# Simple-Math-Game

- IoT Project

- Descriptions  
    - Two random numbers were popped up on an LCD screen.
    - Added them up and entered the answer using buttons.
    - If the answer is correct, the screen will display "correct"; otherwise, it will display "wrong"

- tools:
1. Breadboard
2. Arduino Board
3. LCD I2C Screen
4. 3 Buttons
5. 3 1 kΩ resistors
